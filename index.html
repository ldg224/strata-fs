How to get your landing data

Use a flight-data recorder with Microsoft Flight Simulator, then enter the three landing values here.

Recommended: Landing Guide

Landing Guide is a current Microsoft Flight Simulator landing-analysis utility. It can record landing data and save fixed-wing landing results as CSV files, including touchdown vertical speed, G-force and other landing measurements.

Open Landing Guide on Flightsim.to
  1. 1

    Install Landing Guide

    Download it from Flightsim.to and extract the complete package to a normal writable folder. Keep the supplied files together.

  2. 2

    Start the tool and Microsoft Flight Simulator

    Run Landing Guide.exe, then start or continue a flight in MSFS. The tool connects to the simulator through SimConnect.

  3. 3

    Enable landing analysis

    In Landing Guide, enable the Landing Analysis Window. The tool can detect touchdown and record the landing automatically.

  4. 4

    Complete your landing

    Fly the approach normally and land. After touchdown, open the landing analysis result and use the recorded values for your flight log.

  5. 5

    Enter the three values

    Strata field Landing Guide value
    Vertical speedTouchdown FPM / vertical speed
    Touchdown G-forceTouchdown G / G-loading
    Bank angleTouchdown bank angle
  6. 6

    Save the flight

    Add the basic flight details, optionally write a note, and select Save flight. The result is added to your local logbook.

Where the recorded files are stored

Landing Guide stores its landing records in the Logs folder beside the application. Fixed-wing landing results are written to files named like fixedwing_landings_*.csv.

What you need

For the simplest workflow:

  • Microsoft Flight Simulator
  • Landing Guide
  • Your aircraft and landing
  • Three landing values

Need more flight data?

For full-flight recording and CSV export, Flight Recorder is another established Flightsim.to utility. It records simulator variables and can export recorded data to CSV or KML.

Important

This tool does not connect directly to your simulator. The landing values are entered manually from your recorder. Always use the simulator or aircraft documentation for operating limits and training decisions.
